# Task 015 Reliability Gate Matrix

This matrix is the evidence ledger for the final reliability gate before Windows packaging. Automated rows use only deterministic models, local/mock HTTP, injected timers/sleepers, and temporary directories. Failed evidence must identify the assertion, log, or captured runtime state; a production change requires that evidence plus a regression test. The unchanged baseline was 233 passed in 49.11 seconds; the final full suite was 280 passed, 0 failed, 0 skipped in 57.19 seconds.

## Release-blocking interpretation

Task 015 cannot pass while any requested automated row is failed or unexecuted. `CHECKLIST READY` means the live Shopee case was deliberately not executed by automation and is handed off in `TASK_015_MANUAL_SOAK.md`; it is not an automated PASS claim. The frozen manual extraction path remains untouched. Packaging is outside this task.
